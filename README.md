# Shoot Gun B

A browser-based first-person shooter project built as a standalone HTML game.

Shoot Gun B is designed to be easy to try: download the game file, open it in a modern browser, and start playing. This repository is a work in progress, so gameplay features, controls, and browser support may change as development continues.

## Play the game

### Run locally

1. Open the **[Shoot Gun (1).html](./Shot%20Gun%20(1).html)** file in this repository.
2. Download it to your computer.
3. Double-click the downloaded HTML file, or right-click it and choose **Open with** your browser.
4. If your browser asks for permission (for example, pointer lock), allow it when you want to use the relevant game controls.

No Python, Node.js, or separate installation step is documented as required by the current repository.

> **Note:** The repository currently contains the game as `Shot Gun (1).html`. Use that exact filename; older instructions referring to `ShotGun.html` do not match the current file name.

## Development

The game is currently provided as a standalone HTML file. To experiment with the project:

1. Fork or clone this repository.
2. Make a backup of the original HTML file.
3. Edit the game file using a code editor.
4. Open the updated HTML file in your browser and test it.
5. Commit and push your changes when they are ready.

If you add external assets, libraries, or setup steps, document them here so other people can run the game reliably.
